# 觀察筆記

追蹤台股 ETF 與個股的個人觀察筆記。每天記錄行情與自己的見解，整理成「今日回顧」與「每週回顧」，用來檢視自己的判斷。

> **這是作業示範版。** 行情是從臺灣證券交易所讀取的實際資料；「見解」全部是範例文字，不是任何人的真實投資紀錄。本站所有內容都不是投資建議。

## 功能

- **關注清單儀表板**：每檔標的的最新收盤、漲跌與迷你走勢。
- **標的頁**：走勢圖（折線與 K 線可切換）、區間統計、觀察條件、見解紀錄、每日行情表。
- **今日回顧／每週回顧**：行情表、我的見解、與先前見解對照、觀察條件檢查、待追蹤問題。
- **我要更新**：在首頁填寫今天的見解或想新增的標的，產生一段訊息貼給 AI，由 AI 寫入資料。
- 行情數字與「條件是否觸發」都由程式從資料計算，不靠 AI 手動填寫。

## 怎麼運作

所有規則寫在 [CLAUDE.md](CLAUDE.md)。使用者每天只要對 AI 說「更新今天」並說出自己的看法，AI 會依手冊：

1. 從證交所讀取當天行情，加進 `data/prices/`。
2. 把使用者的原話存到 `raw/notes/`。
3. 寫出 `data/reviews/` 裡的回顧檔，並登記到 `data/manifest.js`。
4. 用瀏覽器檢查頁面，回報結果。

新增一檔標的或一篇回顧都只需要新增資料檔，不必修改任何 HTML。

## 資料夾

- `index.html`、`stock.html`、`review.html`：三種頁面。
- `assets/`：樣式與程式。
- `data/`：關注清單、行情、回顧。
- `raw/notes/`：見解原文。
- `log.md`：更新日誌。

## 技術

純 HTML、CSS、原生 JavaScript，沒有使用任何框架或外部函式庫。可部署在 GitHub Pages，也可以直接用瀏覽器開啟 `index.html`。
